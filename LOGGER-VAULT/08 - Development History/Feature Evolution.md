# 📈 Feature Evolution — Journey of Logger

> **Tag**: #history #evolution
> **Related Notes**: [[CHANGELOG]], [[Key Design Decisions]]

Logger progressed through several generational leaps:
1. **v1.0 (March 2026)**: Local IndexedDB prototype for logging films.
2. **v1.2 (March 2026)**: Switched to Firebase Auth & Firestore for real-time sync.
3. **v1.7 (March 2026)**: Public profile URLs (`?u=UID`) and share cards.
4. **v2.1 (August 2026)**: Cloudflare Worker API proxy and migration to Twitch IGDB v4.
5. **October 2026**: Transitioned from experimental canvas graph view to the high-performance Movie Wall.
