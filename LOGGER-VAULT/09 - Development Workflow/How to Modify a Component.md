# 🔧 How to Modify a Component

> **Tag**: #workflow #guide #components
> **Related Notes**: [[AI Development Rules]], [[PROJECT-MAP]]

1. **Locate Code**: Consult [[PROJECT-MAP]] for line numbers of the component in `index.html`.
2. **Read Surrounding Context**: View 50-100 lines above and below to understand scoped variables and event listeners.
3. **Make Surgical Edits**: Replace only the necessary functions or markup.
4. **Preserve Event Bindings**: Ensure listeners (clicks, keydowns, swipes) remain attached.
5. **Verify in Browser**: Test on both desktop and mobile viewports.
