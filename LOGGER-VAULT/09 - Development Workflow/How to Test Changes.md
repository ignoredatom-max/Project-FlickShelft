# 🧪 How to Test Changes

> **Tag**: #workflow #testing #verification
> **Related Notes**: [[Testing Strategy]]

## Pre-Commit Verification Checklist
- [ ] **Syntax Compilation**: Node.js VM script execution passes without errors.
- [ ] **Local Server HTTP 200**: `node server.js` serves the application cleanly.
- [ ] **Responsive Check**: Test at 375px (mobile) and 1440px (desktop).
- [ ] **Diary Flow**: Add a new film, rate it, add notes, verify it appears in the log.
- [ ] **Watchlist Flow**: Drag to reorder, swipe right to log, swipe left to delete.
- [ ] **Movie Wall Flow**: Open Movie Wall, test category filters, trigger Share picture.
