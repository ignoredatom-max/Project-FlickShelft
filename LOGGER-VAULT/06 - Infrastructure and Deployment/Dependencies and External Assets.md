# 📦 Dependencies & External Assets

> **Tag**: #dependencies #cdn
> **Related Notes**: [[Technology Stack]]

All dependencies are loaded via reputable global CDNs:
- **Firebase SDK (v10.12.0)**: `gstatic.com/firebasejs` (Auth & Firestore).
- **html2canvas (v1.4.1)**: `cdnjs.cloudflare.com/ajax/libs/html2canvas`.
- **Google Fonts**: *Inter* and *Playfair Display* via `fonts.googleapis.com`.
