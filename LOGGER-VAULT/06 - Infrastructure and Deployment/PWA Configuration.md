## Manifest Configuration (`../manifest.json`)
- **Display**: `standalone` (hides browser chrome).
- **Theme Color**: `#0d0d0f` (matches app base background).
- **Icons**:
  - `icon-192.png` (192x192 px, maskable).
  - `icon-512.png` (512x512 px).
- **Installation**: Automatically surfaces native installation prompt on Android and iOS Safari.
