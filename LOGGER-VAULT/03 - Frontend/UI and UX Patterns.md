# 📐 Frontend: UI & UX Patterns

> **Tag**: #ux #patterns #interactions
> **Related Notes**: [[Design System]], [[Navigation System]], [[Watchlist Page]]

## Key UX Patterns
1. **Letterboxd-Inspired Data Density**: Compact rows maximizing visible content per viewport height.
2. **Haptic Micro-Interactions**: `navigator.vibrate()` pulses on tab navigation, favorite toggles, and rating changes.
3. **Spring Press Feedback**: `transform: scale(0.96)` tactile bounce on buttons and cards.
4. **Optimistic Local Reflection**: UI updates immediately on user input before network confirmation.
5. **Keyboard-Proof Viewports**: Floating cards anchored to safe areas to prevent mobile virtual keyboard distortion.
