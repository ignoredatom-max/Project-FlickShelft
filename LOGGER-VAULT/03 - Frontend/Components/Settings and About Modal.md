# 🧩 Component: Settings and About Modal (`#settingsModal`)

> **Tag**: #component #settings #about
> **Related Notes**: [[Application Shell]], [[Firebase Authentication]]

## Purpose
Settings sheet for account management, cloud sync status, data backup/restoration, and ATOMYN support links.

## Implementation Details
- **Source**: `index.html` (`openSettings()`)
- **Controls**: Google Sign-in/Sign-out, Export Diary (JSON download), Import Diary (JSON merge), TMDB/IGDB attribution links, and developer contact channels.
