# 🎯 Product Vision — Aesthetic & Functional Ideals

> **Tag**: #vision #design-philosophy
> **Related Notes**: [[Project Overview]], [[Design System]], [[UI and UX Patterns]]

## 1. Design Principles
1. **Frictionless Logging**: Adding or rating a movie should take less than 3 seconds. Pre-filled search results, quick-status buttons, and a tactile rating slider eliminate typing friction.
2. **Visual Richness Over Text Clutter**: Media is visual. The app prioritizes movie posters, backdrops, and cover art over dense text blocks. The [[Movie Wall]] embodies this principle by showcasing collections without labels.
3. **Respect for Personal Taste**: Rather than displaying complex decimal review aggregators, Logger uses an emotive 5-stage scale: *Skip, Mediocre, Decent, Excellent, Peak*.
4. **Offline First, Cloud Always**: Entries load instantly from local memory before network validation. Cloud Firestore silently synchronizes changes in the background.

## 2. Target Audience
- Cinephiles, television binge-watchers, and gamers who want a unified record of their media consumption.
- Users who value fast, clean mobile web applications over native app store downloads.
